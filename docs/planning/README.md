# Planning

This folder is this repository's own planning space, kept by the very
discipline this repository ships — the plugin builds itself under its
own rules.

- `worklog.md` — one entry per change, any size, newest first: who,
  why, how, commit reference.
- `active/<slug>/` — one folder per piece of multi-session work:
  `contract.md` (agreed intent), `work.md` (plan, status, exact next
  action — the only place status lives), `decisions.md` (dated
  decisions with the why), `research/` (probe findings).
- `research/` — standalone probe notes not tied to one initiative.
- `archive/<year>/` — finished initiative folders.

Everything here is written as work happens, not reconstructed after.
A fresh session reading this folder alone should be able to state the
goal, the status, the material decisions, and the exact next action.
