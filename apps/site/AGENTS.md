# site

The stem.cooking landing page (Astro, static). Design is a later
initiative — this is the shell.

- Brand values (name, domain, tagline) come from `src/data/brand.ts`
  and nowhere else; never hardcode them in pages.
- Start the dev server in background mode: `astro dev --background`;
  manage it with `astro dev stop`, `astro dev status`, `astro dev logs`.
- Framework docs: <https://docs.astro.build>
